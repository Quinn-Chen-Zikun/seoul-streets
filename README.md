# 首尔街头

在阳光鲜明的首尔街巷与汉江两岸步行、驾车、接取委托，或自由探索城市。第三人称视角，支持桌面键鼠与手机横屏触控。

[开始游玩](https://quinn-chen-zikun.github.io/seoul-streets/)

也可直接打开 `index.html`，或打开单文件版 `single.html`。两者内容、操作与存档格式相同；三维引擎及后期效果从 CDN 载入，首次加载需要网络。浏览器禁用存储时仍可游玩，但关闭页面后不会保留本次进度。

## 初到首尔

点击「走进首尔」或「新游戏」。首分钟的单行提示依次介绍移动、上车、沿小地图金色 GPS 路线前进，以及在金色圆环接任务；完成动作会提前进入下一条。手机显示摇杆和触控按钮名称。

出生点西侧有一辆准备好的出租车。靠近按 F 上车，跟着金线返回联系人；停稳下车后靠近金色 H 圆环，按 E 听取韩序温的简报，继续对话并接受任务。也可以直接步行接任务。首章会带你完成送单、近战和摆脱一星。遇到通缉时，先离开红色搜索圈并躲开巡警，再接委托。

## 手机与平板

建议横屏。按住左侧下半屏出现浮动摇杆，右侧空白处拖动环顾；按住攻击按钮可连续射击并拖动瞄准。步行时有跳跃、疾跑、上车、瞄准、收枪与切换武器按钮。

上车后，左摇杆控制转向，右侧油门与刹车／倒车踏板控制速度，并提供手刹、鸣笛、后视、下车和车内射击。可同时转向、加速和攻击。松手、取消触摸、切换驾驶模式或暂停会释放输入。

靠近联系人、目标物品或柜台后点交互条。点右上角弹药换弹，受困约 3 秒后同一位置会显示「复位」。地图支持双指缩放；地图、暂停、全屏均有按钮。暂停页提供任务日志、步行模式、换装、街头档案、扬招出租车、切台和设置。

## 街头生活

- **驾驶与战斗**：轿车、出租车、跑车、SUV、皮卡、厢车、公交、配送摩托与警用车辆；车身按真实侧面轮廓生成，带独立车窗与立柱、门缝、灯组、后视镜、轮辋和刹车盘，近景与远景分级显示；车损、冒烟、起火、爆炸、手刹漂移、轮胎痕迹和车辆复位。徒手、手枪、冲锋枪、棒球棍、霰弹枪与榴弹发射器有独立弹药和换弹；车内可用手枪、冲锋枪和霰弹枪。
- **警方追捕**：目击者会报警，盗车、袭击和开枪可升高通缉。一星出现步警，两星加入追车，三星警员开枪，四星增加路障、扎胎带及特警，五星加入装甲支援与直升机。断开视线并离开搜索圈后，星星闪烁并逐级消失。
- **故事委托**：七章「账本风波」衔接十二章「白鸥之下」，共 19 章。金色 H / Y / C 分别对应韩序温、尹海率和蔡娜凛。目标自动保存检查点，失败可立即重试；日志可暂存主线或结束支线。完成获得现金、声望、武器或服装，并点亮下一章标记。
- **自由活动**：出租车、配送、计时赛、街区解围、楼顶寻物、机场、街演、两岸工作，以及踏板车急送、警车追停、限时战斗与三桥赛。青绿色圆环是工作起点；正式委托期间不生成新偶遇。
- **探索与房产**：100 只招财猫与四处特技跳跃，已完成项目不会重复发奖。乙支路工房、弘大练歌房、汝矣岛公寓和江南车行可购买，提供休息存档、换装、存取一辆车和领取收入。房产每两分钟实际游玩时间产生收入，最多积攒 12 笔。
- **城市漫游**：九座跨江桥梁、明洞商业街、江南高楼、南山塔、停车场、公园、工地、校园球场和江岸营地。近景行人使用骨骼模型、可辨识的面孔、多款发型与职业服装，衣服、裤子与鞋为独立布料外壳，中远距离退回程序化人群；他们沿人行道行走、在路口等灯，也会候车、休息、看手机或撑伞；轿车、出租车、SUV、皮卡与警车使用模型外壳，公交、厢车、摩托等仍由几何体生成；街上有紧急车辆，岸边有骑行者、猫与鸽子。
- **道路与地形**：主次干道共用一套连续高程曲线，路口同高、坡度受控；桥头、匝道与路堤按长度平顺过渡，路面、人行道、路缘石、标线与人行横道贴合同一坡面，车辆与行人踩在可见地面上。
- **昼夜与声音**：日落、夜间霓虹、逐户窗光、晴天、阵雨、黄沙薄霾和雪景。阵雨会在路面留下缓慢积水的水膜，反光随视角变化，并伴有雨丝、溅水、车轮水雾和车内雨刷。四个车载电台提供原创合成音乐及交通字幕；枪声、发动机、警笛与环境声随距离变化。暂停页可调音量或静音，任务期间不能手动改变时刻与天气。

金色任务目标位于顶部，左上小地图附生命与护甲条，右上显示现金、通缉、时间和弹药，驾驶速度与车况位于右下。进入街区时只短暂显示一次名称。

倒下后在医疗站复活，扣除至少 ¥150 或现金的 8%（不超过余额），时间推进三小时；保留武器和备弹，弹匣清空。被捕后在治安站释放，扣除 ¥120 加每星 ¥170（不超过余额），没收武器与弹药，时间推进四小时。

## 存档与画质

「继续游戏」恢复章节检查点，安全屋休息后从该处出生。「新游戏」重置故事、资金、装备和人物状态。现金、生命、护甲、时间、武器弹药、外观、章节、支线次数、声望、收藏、房产车库与统计保存在当前浏览器。不同网址或浏览器的存档互相独立。

设置可调普通与瞄准灵敏度、垂直反转、昼夜速度、镜头起伏、伤害数字和高／中／低／自动画质。自动画质会根据运行状况调整远景、人群、交通与分辨率；切出页面会暂停。遇到画面卡顿可降低画质，音量和静音独立保存。

出租车乘坐采用付费抵达，公交候车者到站后散开；翻越仅覆盖窄低障碍，落水会返回安全岸边。榴弹使用即时射线爆炸，新闻使用字幕，桥赛为计时赛。城市是风格化舞台，并非精确地理复原；复杂交叉口的长车转弯、车队避障与高星追捕仍可能出现不自然的行为。

## 演示与自检

在地址后加 `?autostart=1` 可直接进入游戏并运行约二三十秒分阶段自检，控制台逐项显示 `SMOKE stage … ok`；其中 `road-continuity` 以两米间距回放全部道路中心线，检查高差、坡度、坡度变化和路口／桥头衔接，`rain-stability` 在固定机位连续渲染雨湿路面并回读亮度，检查帧间闪烁，`m17-model-*` 检查骨骼人物、服装遮罩、步态与驾驶动画以及车辆模型，`m18-clothing-*` 检查每位近景人物的上衣、下装与鞋外壳、布料贴图、放松手指和 `Idle_Loop` 并输出服装三角面，`m18-pedestrian-pavements` 验证 drive／mission 展示镜头只在人行道布置行人，`m19-sleeve-skinning` 与 `m19-hem-hat-skinning` 让 `Idle_Loop` 播放一秒后按骨骼矩阵在 CPU 上重建袖口、裤脚与帽子的世界坐标，输出并限制它们到手臂、腿部与头部骨骼的距离；中画质运行预算按最多 10 个近景骨骼行人计算，上限为 520 次绘制与 90 万三角面。加 `&shot=rain` 可跳过自检，停在雨中街道展示镜头；其余展示名为 `street`、`drive`、`night`、`river`、`chase`、`mission`、`map`、`slope`、`closeup`、`carclose`。`node tools/audit-city.js --loop` 可离线执行同一套检查。

游戏使用 three.js r128。建筑、道路、街景、服装细节与特效由几何体和画布纹理生成；近景人物与部分车辆使用 `assets/models/` 中的 CC0 模型；人物身体用顶点遮罩隐藏被衣服覆盖的部分，上衣、下装与鞋是共享骨架的独立外壳：袖口与裤脚顶点按绑定姿态投影到肩／肘／腕和髋／膝／踝的骨段上分配权重，袖口内折收边，材质开启骨架蒙皮后随待机、行走与驾驶动画一起变形，并贴有画布生成的布料纹理。，声音由 WebAudio 合成。模型需要 http(s) 加载，从 `file://` 直接打开或加载失败时会自动退回程序化人物与车辆。脚本按页面中的顺序共享 `window.SN`，两种入口均支持直接从本地文件打开及 GitHub Pages。
